First create an empty Github Repo. (Do not add a readme.md or a template)

When you open the repository it will show something like this:

echo "# Example-Crud" <br>
>> README.mdgit init <br>
git add README.md <br>
git commit -m "first commit" <br>
git branch -M main <br>
git remote add origin https://github.com/DennisVanStrien/Example-Crud.git (Replace the link with YOUR link) <br>
git push -u origin main <br>

Copy and paste the above in the terminal of your project (With some changes). When you open the Github Repository it should contain all the files.
If it does not follow these steps: (Don't copy the text in the brackets) <br>

git add . (This adds all the files in the project to changes) <br>
git commit -m "message" (This adds a message to your changes/commit. Every commit requires a message) <br>
git push (This pushes your changes to the branch/repo, quite self-explanatory.) <br>

These steps should make sure that you have added all of the items in your project to your Github Repository.
If not, then idk. This worked for me.

### Important
When you create an empty github repository, it should show you the same steps, except for the final steps I gave for when your branch still is empty. I recommend to follow github's steps first, as that is more clear and straight forward for most people.
