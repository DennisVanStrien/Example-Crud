## using github via the terminal

git status - view the files that you've changed.
git add . - Stage all changes
git commit -m "Message" - adds a message to your commit (To push your commit needs a message)
git push - sends the commit to the git
git pull - retrieve all the new changes


git branch - check on which branch you're currently working (The terminal will show all branches, the one highlighting in green (might be another color for you) with a asterik (*) in front of it is the branch that is currently selected.)
git branch "name" - makes a new branch, for example: git branch testingBranch
git switch "branch name" - switches to another branch
