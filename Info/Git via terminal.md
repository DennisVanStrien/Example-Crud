## using github via the terminal

git status - view the files that you've changed. <br>
git add . - Stage all changes <br>
git commit -m "Message" - adds a message to your commit (To push your commit needs a message) <br>
git push - sends the commit to the git <br>
git pull - retrieve all the new changes <br>


git branch - check on which branch you're currently working (The terminal will show all branches, the one highlighting in <br> green (might be another color for you) with a asterik (*) in front of it is the branch that is currently selected.) <br>
git branch "name" - makes a new branch, for example: git branch testingBranch <br>
git switch "branch name" - switches to another branch <br>
